NEON ESCAPE — Source Code Edition
=================================

A self-contained, browser-based arcade game built with HTML, CSS and vanilla JavaScript.
No build tools, server, account or paid software is required.

HOW TO PLAY
-----------
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Press PLAY NOW.
4. Move by touching/dragging inside the game area, or use Arrow keys / WASD.
5. Avoid pink barriers and red hazards. Collect golden gems.
6. Press the pause button or Escape to pause.

FILES
-----
index.html  Main page and game layout
style.css   Responsive visual design
game.js     Game mechanics, controls, scoring and saved best score
README.txt  This guide
